Project Description: File Organizer in Python

This project is a Python-based File Organizer that automatically manages and organizes files in a folder according to their file types. It scans a selected Downloads folder, identifies file extensions such as .jpg, .pdf, .mp4, .mp3, and .docx, and moves each file into its respective category folder.

The project uses Python's os module for file and directory operations and the shutil module for moving files. It reduces manual effort, keeps folders clean, and makes files easier to find.

Key Features:
* Automatically detects the Downloads folder location.
* Organizes files based on their extensions.
* Creates category folders automatically.
*  Moves files into appropriate folders.
 * Saves time and reduces folder clutter.

Technologies Used
  Python
  os module
  shutil module
